# ScraperExample
Example code for polite web scraper

1. Create a new folder and copy all this project's files into it.

2. Create a new virtual environment inside the folder:
python -m venv .venv

Note: on macOS you might need to use:
python3 -m venv .venv

3. Activate the venv:

Activate — Windows (PowerShell):
.venv\Scripts\Activate.ps1

Activate — Windows (cmd):
.venv\Scripts\activate.bat

Activate — macOS / Linux:
source .venv/bin/activate

4. Install the required libraries:
pip install requests selectolax
